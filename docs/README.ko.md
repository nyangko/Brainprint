## Brainprint는 무엇인가?

Brainprint는 소프트웨어 프로젝트에 대한 이해를 지속적으로 최신 상태로 유지하고, AI 코딩 에이전트가 현재 작업에 필요한 컨텍스트만 받아볼 수 있도록 만드는 **로컬 우선 공유 컨텍스트 런타임**입니다.

현재의 AI 코딩 에이전트는 세션이나 에이전트가 바뀔 때마다 저장소 구조, 심볼, 의존 관계, 프로젝트 결정과 규칙을 반복해서 탐색하는 경우가 많습니다. Brainprint는 이런 이해를 지속적으로 유지하여 반복 탐색을 줄이고, 에이전트가 실제 작업에 더 빠르게 들어갈 수 있도록 하는 것을 목표로 합니다.

저장소와 Git은 현재 코드의 기준이며, Brainprint는 백업 시스템을 대체하지 않습니다. Brainprint가 유지하려는 것은 저장소 주변의 구조화된 프로젝트 이해와 작업 컨텍스트입니다.

## 앞으로 어떻게 진행되나?

Brainprint는 현재 **초기 설계 및 구현 단계**입니다.

첫 번째 버전은 **코드 개발 워크플로우**에 집중합니다.

1. 프로젝트의 리소스, 심볼, 실제 위치, 관계 정보를 최신 상태로 유지합니다.
2. 저장소 전체를 매번 다시 분석하지 않고 변경된 부분을 증분 방식으로 갱신합니다.
3. AI 에이전트가 사용할 수 있는 작고 예측 가능한 인터페이스를 통해 필요한 컨텍스트만 제공합니다.
4. 프로젝트 결정, 규칙, 현재 작업 상태를 세션과 에이전트가 바뀌어도 이어갈 수 있도록 합니다.
5. 실제로 파일 재탐색, 도구 호출, 입력 토큰, 탐색 시간이 줄어드는지 정확성과 함께 벤치마크합니다.

코드 개발 워크플로우에서 효과가 검증된 뒤에는 같은 핵심 모델을 문서, 이미지, 영상, 오디오와 같은 다른 프로젝트 리소스로 확장할 수 있도록 고려합니다. 다만 초기 버전부터 범용 지식 플랫폼을 만드는 방향은 피합니다.

## 현재 상태

**초기 개발 / 설계 검증 단계**

구조와 우선순위는 실제 구현과 벤치마크를 통해 계속 검증하고 있습니다. 첫 번째 실용적인 코드 개발 워크플로우가 검증되기 전까지 인터페이스와 저장 구조는 변경될 수 있습니다.
