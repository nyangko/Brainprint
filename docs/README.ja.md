## Brainprint とは？

Brainprint は、ソフトウェアプロジェクトに対する理解を継続的に最新状態へ保ち、AI コーディングエージェントに現在の作業で必要なコンテキストだけを提供するための **ローカルファースト共有コンテキストランタイム**です。

現在の AI コーディングエージェントは、セッションやエージェントが変わるたびに、リポジトリ構造、シンボル、依存関係、プロジェクト上の決定やルールを繰り返し探索することがあります。Brainprint は、その理解を持続的に維持することで重複した探索を減らし、エージェントが実際の作業へより早く進めるようにすることを目指します。

現在のコードに対する信頼できる基準はリポジトリと Git です。Brainprint はバックアップシステムを置き換えるものではなく、リポジトリの周辺にある構造化されたプロジェクト理解と作業コンテキストを維持します。

## 今後の進め方

Brainprint は現在、**初期設計・実装段階**です。

最初のバージョンでは **コード開発ワークフロー**に集中します。

1. プロジェクトのリソース、シンボル、出現位置、関係情報を最新状態に保ちます。
2. 毎回リポジトリ全体を再解析せず、変更された部分だけを増分更新します。
3. AI エージェント向けの小さく予測可能なインターフェースから、必要なコンテキストだけを提供します。
4. プロジェクト上の決定、ルール、現在の作業状態をセッションやエージェントをまたいで維持します。
5. ファイルの再読込、ツール呼び出し、入力トークン、探索時間を本当に削減できるかを、正確性と合わせてベンチマークします。

コード開発ワークフローで効果が確認できた後は、同じコアモデルをドキュメント、画像、動画、音声などの他のプロジェクトリソースへ拡張できるようにします。ただし、初期段階から汎用ナレッジプラットフォームにすることは避けます。

## 現在の状態

**初期開発 / 設計検証段階**

アーキテクチャと優先順位は、実装とベンチマークを通じて継続的に検証しています。最初の実用的なコード開発ワークフローが検証されるまでは、インターフェースや保存方式が変更される可能性があります。
